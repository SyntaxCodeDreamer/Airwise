
# AI Engineering Instructions

## ECC Integration
- Follow the installed ECC skills and rules.
- Inspect relevant skills before each task.
- Use planning before major implementation.
- Follow TDD where appropriate.
- Use debugging workflows for errors.
- Perform code reviews after major changes.
- Apply security best practices.

## Development Rules
- Understand existing code before modifying it.
- Maintain the existing architecture.
- Write clean, reusable and maintainable code.
- Avoid unnecessary dependencies.
- Test all important changes.
- Never claim tests passed without running them.

## Reporting
After each task, explain:
- Changes made
- ECC skills used
- Files modified
- Tests performed
- Remaining issues
